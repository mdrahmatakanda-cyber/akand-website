# Akand Smart Solutions — Website

## এই ভার্সনে যা যা আছে

- ৪ ভাষা (বাংলা/আরবি/উর্দু/ইংরেজি) — `locales/*.json` + `data-i18n` সিস্টেম
- **ডার্ক/লাইট মোড** — CSS variable-ভিত্তিক (`:root` / `html.dark`), header-এর সূর্য/চাঁদ বাটনে টগল হয়, পছন্দ `localStorage`-এ মনে থাকে
- **স্ক্রল প্রোগ্রেস বার** — পেজের একদম উপরে, স্ক্রল অনুযায়ী পূর্ণ হয়
- **ফ্লোটিং পিল হেডার** — ৫০px স্ক্রল করলে হেডার ছোট হয়ে ভাসমান পিল-শেপে চলে আসে
- Services (৩টা) ও Industries (১০টা) সেকশন — Hero-র পর, Products-এর আগে
- Products, Why-us, Contact, Footer — সব ৪ ভাষাতেই dynamic রেন্ডার হয়

## এখনো করার বাকি (ঐচ্ছিক)

1. **লাইভ ডেমো লিংক** — `locales/*.json`-এ প্রতিটা প্রোডাক্টে একটা `demoUrl` ফিল্ড যোগ করে product.html-এ বাটন হিসেবে বসিয়ে দিতে পারবেন
2. **প্রোডাক্ট স্ক্রিনশট** — `assets/products/` ফোল্ডারে এই নামে ছবি রাখুন, স্বয়ংক্রিয়ভাবে দেখাবে:
   - `shop-management.jpg`, `madrasa-management.jpg`, `school-management.jpg`, `mess-management.jpg`
   - ছবি না থাকলে "স্ক্রিনশট শীঘ্রই" প্লেসহোল্ডার দেখাবে
3. **স্ট্যাটস সেকশন / সোশ্যাল মিডিয়া আইকন** — আগে আলোচনা হয়েছিল, বাস্তব সংখ্যা/লিংক রেডি হলে যোগ করা যাবে

## লোকাল প্রিভিউ

`fetch()` দিয়ে JSON লোড হয় বলে সরাসরি ফাইল ডাবল-ক্লিক করে (`file://`) খুললে কাজ করবে না। লোকাল সার্ভার লাগবে:

```bash
cd site
python3 -m http.server 8000
# তারপর ব্রাউজারে: http://localhost:8000
```

## ডিপ্লয়

- **Vercel:** GitHub repo বানিয়ে push করুন, vercel.com এ import করলেই অটো-ডিপ্লয় হবে
- **Cloudflare Pages / Netlify:** একই পদ্ধতি, অথবা পুরো `site` ফোল্ডার ড্র্যাগ-ড্রপ করেও deploy করা যায় (Netlify Drop)

## পরবর্তী ধাপ (পারফরম্যান্স অপ্টিমাইজেশন)

এখন Tailwind CDN দিয়ে প্রোটোটাইপ করা — লঞ্চের আগে Tailwind CLI দিয়ে একবার build করে শুধু ব্যবহৃত ক্লাসগুলোর একটা ছোট CSS ফাইল বানিয়ে নেওয়া উচিত (page load আরও দ্রুত হবে)। প্রয়োজনে বলবেন, এই ধাপটাও করে দেব।

## স্ট্রাকচার

```
site/
├── index.html                 # হোমপেজ
├── products/
│   └── product.html           # সব প্রোডাক্টের জন্য একটাই টেমপ্লেট (?id=... দিয়ে আলাদা হয়)
├── locales/
│   ├── bn.json  ar.json  ur.json  en.json
├── js/
│   ├── effects.js             # পেজ ট্রানজিশন, কার্সার-গ্লো, SVG draw-in হেল্পার
│   ├── header-progress.js     # স্ক্রল প্রোগ্রেস বার, ফ্লোটিং হেডার, ডার্ক/লাইট টগল
│   ├── i18n.js                # ভাষা লোড/সুইচ ইঞ্জিন
│   └── main.js                # অ্যানিমেশন, প্রোডাক্ট/হোয়াই-আস/ইন্ডাস্ট্রি রেন্ডার, কন্টাক্ট ফর্ম
```
